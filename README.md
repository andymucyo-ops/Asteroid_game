# Asteroid Game

project from [boot.dev](https://boot.dev)
Note: logger.py and asteroidfield.py modules were not written by me but retrieved from the [boot.dev](https://boot.dev)  website

## Requirement
uv, python 

## How to run

- clone this repo: 
```{bash}
git clone https://github.com/andymucyo-ops/Asteroid_game
```
- sync the python environment with 
```{bash}
uv sync
```

- then from the root of the directory run:
```{bash}
uv run main.py
```

## Game commands

- a = rotate left
- d = rotate right
- w = move forward
- s = move backward
- SPACE = shoot

Enjoy
